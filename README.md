# Xenon2 downloads

Download page for **Xenon2**, a private AI chat assistant that runs entirely on your own
Windows PC. This repository only hosts the installer and the AI model files. The app's source
code is not public.

## Install

1. Open [Releases](../../releases) and download the latest `Xenon2_..._x64-setup.exe`.
2. Run it. On first launch, Xenon2 downloads a chat model from this page by itself.
